# MiniGolf

Proyecto de minigolf en Unity 6000.5.10f1 (URP).

## Abrir y jugar

1. Agregar esta carpeta en Unity Hub y abrirla con Unity 6000.5.10f1.
2. Abrir Assets/Scenes/MenuPrincipal.unity.
3. Pulsar Play y después JUGAR.

Arrastra la pelota hacia atrás y suelta para golpear. Clic derecho cancela el tiro o gira la cámara; la rueda ajusta el zoom y R reinicia la pelota. Al completar el hoyo se muestra la victoria y se recarga el nivel.

## Recursos

Incluye recursos de Unity Asset Store: Stylized Mini Golf (Anni) y Low-Poly Simple Nature Pack (JustCreate), sujetos a sus licencias originales. El código del proyecto no cambia las licencias de estos recursos.

Unity regenera Library y los demás archivos temporales al abrir el proyecto.
